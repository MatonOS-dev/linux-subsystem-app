The fork branch is `matonos/v26.10-update`. Merge `effac9a9` joins
`8078df14` and upstream/main `e6febd33` (54 upstream commits). A fresh upstream

## Merge and restoration resolutions

- The merge's sole content conflict was in `meson.build`: retain the removal
  of AppStream/gdk-pixbuf at that stage, and take upstream's replacement of
  gtk-doc with gi-docgen. The musl recipe now uses `-Dapi_docs=disabled`.
- Reverting `cff1a38a` caused a dependency-block conflict in `meson.build`:
  restore `appstream_dep`, keep `gdk_pixbuf_dep` removed.
- The revert applied cleanly but restored obsolete search/remote-list code.
  Use current upstream `app/flatpak-builtins-search.c` and
  `app/flatpak-builtins-remote-ls.c` in full, preserving recent fixes rather
  than reintroducing older implementations.
- FUSE/revokefs and the gdk-pixbuf icon validator stay removed. TMPDIR-aware
  seccomp temporary files, no-system-bus handling and the `flatpak/<version>`
  HTTP User-Agent remain. None of these carried changes became redundant in
  this upstream range; none was dropped as upstreamed.

## Changes that matter to MatonOS

Upstream selects apps/runtimes from the requested installation correctly,
limits portal-spawned children to the buses their caller had, and records
missing buses in instance metadata. It fixes search crashes on nameless
components, adds app/runtime search filters, improves large search performance,
flattens multiline summaries, and reads remote AppStream for the requested
architecture. Other useful changes include truncated HTTP response retries,
missing GPG-agent socket crash avoidance, pin/autodelete handling,
flatpakref reinstall/or-update support, and avoiding AppStream network refresh
with `update --no-pull`.

## Static build and licensing

AppStream 1.2.3 and libfyaml 0.9.6 use hash-checked release archives.
libxmlb 0.3.29 was already locked and built. Current AppStream requires
libfyaml, not libyaml. Optional compose/Qt/stemming/systemd/display integrations
are disabled. No xdg-desktop-portal or xdg-dbus-proxy is added.

AppStream uses a native Meson file inside Alpine, so its build-time tools run
without requiring a separately installed appstreamcli. GLib's resource
compiler is exposed alongside the existing generator wrappers. The recipe
restores AppStream's private static dependencies in its generated pkg-config
file, and removes libfyaml's invalid literal `none required` linker arguments
on musl. The archive extraction handles AppStream's leading `./` directory.
Cached immutable Git commits can be fetched offline; missing-commit fetch
failures now identify the component/revision rather than being swallowed.

AppStream/libxmlb use the LGPL-2.1 option and libfyaml is MIT. Their licence
texts and notices are present in both licence bundles. The pre-existing
malformed trailing fragment in the packaged `linked-components.json` was
removed so the updated manifest parses. No new shipped dependency requires
GPLv3/LGPLv3; existing GCC runtime exceptions remain unchanged. The Alpine
`itstool` and MIME database packages are build/test tools, not shipped inputs.
The existing 22-component licence gate passes.
